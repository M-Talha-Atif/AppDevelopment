Use unbind() to avoid memory leaks.


In addition to memory leaks, failing to unbind View Binding instances can also cause issues with configuration changes. 
For example, if your app is in landscape mode and the user rotates the device to portrait mode, the system will destroy and recreate the activity to apply the new configuration. 
If you haven't properly released the View Binding instance in onDestroy(), the new activity instance will hold a reference to the old instance's views, 
which can cause unexpected behavior.
